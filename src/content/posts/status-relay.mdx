외부 서비스에 의존하는 작업을 하다 보면 문제가 내 코드에 있는지, 사용하는 서비스에 있는지부터 확인하게 됐다. Claude나 Cloudflare 같은 서비스의 상태 페이지를 하나씩 열어보는 대신, 필요한 상태를 메뉴 바에서 바로 볼 수 있는 작은 앱을 만들었다.

StatusRelay는 macOS와 Windows의 시스템 트레이에서 동작한다. 창을 띄워 두지 않아도 여러 서비스의 상태를 확인하고, 상태가 바뀌면 운영체제 알림을 받을 수 있다.

## 메뉴 바에서 상태를 읽기

앱은 Claude, Cloudflare, Render, Replit, Supabase, Vercel, Netlify, Railway, Fly.io의 공개 상태 페이지를 확인한다. 기본 확인 간격은 60초이며, 각 서비스의 상태 페이지 주소를 요청해 현재 상태를 읽는다.

각 서비스 상태는 정상, 저하, 장애 세 단계로 다룬다. 트레이 아이콘에는 확인 중인 서비스 중 가장 심각한 상태를 색상 점으로 표시하고, 메뉴에는 서비스별 상태와 마지막 확인 시각을 보여준다. 서비스 상태가 바뀌면 네이티브 알림으로 알려주고, 메뉴에서 서비스 이름을 누르면 해당 상태 페이지를 열 수 있다.

## Rust와 Tauri로 만든 이유

앱의 핵심은 백그라운드에서 반복적으로 요청하고 상태 변화를 비교하는 일이다. Rust의 비동기 런타임인 Tokio로 주기적인 확인을 처리하고, reqwest로 Statuspage 응답을 가져와 상태를 갱신한다. Tauri 2는 시스템 트레이와 메뉴, 운영체제 알림처럼 데스크톱 기능을 연결하는 데 사용했다.

상태가 달라졌을 때만 알림을 보내도록 이전 값과 새 값을 비교한다. 메뉴 바 아이콘에도 현재 전체 상태를 반영해, 앱을 열지 않고도 문제가 있는지 빠르게 확인할 수 있게 했다.

## 작게 만들고, 바로 확인하기

이 앱이 해결하려는 일은 거창한 모니터링이 아니다. 작업 흐름을 멈추고 상태 페이지를 찾아다니는 수고를 줄이고, 의존하는 서비스에 변화가 생겼을 때 알아차리는 것이다.

실제 화면은 메뉴 바 앱답게 상태 목록과 마지막 확인 시각, 새로고침과 종료 메뉴로 단순하게 구성했다. 지금 필요한 신호만 가까운 곳에 둔 작은 도구다.
