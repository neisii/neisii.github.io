유선 Planck 키보드를 하드웨어 개조 없이 무선으로 쓰는 방법을 구상했다. 키보드 뒤에 붙는 작은 모듈이 USB 입력을 받아 Bluetooth LE로 전달한다면, 익숙한 QMK 레이어와 매크로를 그대로 쓸 수 있을 거라고 생각했다.

## 구상 중인 구조

기획서에서는 LILYGO T-Dongle-S3의 ESP32-S3를 중심으로 USB 키보드 입력을 받고, BLE HID로 맥북에 전달하는 흐름을 잡았다. 보드와 얇은 보호회로 내장 배터리를 가로로 배치하고, Planck 하판에 탈부착할 수 있는 슬림한 하우징을 만드는 것도 목표로 삼았다.

연결 대기와 연결 상태를 LED로 알려주고, 키보드 입력을 재해석하지 않고 전달해 QMK 레이어와 매크로를 유지하는 것을 핵심 요구사항으로 삼았다.

## 지금까지 확인한 것

현재 저장소에 있는 펌웨어는 무선 입력 변환 기능이 아니라 보드 상태를 확인하는 테스트 스케치다. Arduino IDE에서 ESP32-S3 보드 설정과 업로드를 확인하고, 보드의 APA102 LED를 마젠타색으로 점멸시켜 동작을 점검했다.

따라서 USB Host 입력 처리, BLE HID 전송, 배터리와 하우징 통합은 아직 구현하지 않았다. 다음 단계는 보드와 키보드 사이의 USB Host 연결을 검증하고, 입력 보고서를 BLE HID로 전달하는 최소 실험부터 만들려 한다.

## 먼저 작은 연결부터

완성된 변환기 모습을 앞서 가정하기보다, 유선 키 입력을 안정적으로 받아 무선 장치에서 같은 입력으로 확인할 수 있는지부터 나눠 검증하려 한다. 입력 전달이 확인된 다음에야 배터리 지속 시간, 상태 표시, 하우징 두께 같은 제품 조건을 조정할 수 있다.
