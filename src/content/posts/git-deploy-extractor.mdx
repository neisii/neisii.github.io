망 분리 환경에서는 개발망에서 만든 변경 파일을 내부망으로 옮기고, 어떤 파일을 적용하거나 삭제해야 하는지 다시 확인해야 했다. Git Deploy Extractor는 선택한 커밋 이력에서 배포 대상 파일을 모아 별도 패키지로 내보내는 데스크톱 도구다.

## 커밋을 기준으로 변경 파일 계산

저장소와 브랜치를 고른 다음 기간, 키워드, 작성자, 해시 등의 조건으로 커밋을 찾고 필요한 커밋을 선택한다. 선택한 커밋들의 추가·수정·삭제 파일을 경로별로 합쳐 배포 목록을 만든다.

Mapping Profile로 로컬 경로를 서버 경로에 대응시켰다. Export 결과에는 서버 경로로 복사한 파일과 `extract-list.txt`를 함께 넣어 적용 대상과 삭제 대상을 한곳에서 확인하게 했다.

## 배포 준비를 한 흐름으로

Electron, React, TypeScript로 앱을 만들고 Git 작업에는 시스템의 Git CLI를 사용했다. 커밋 분석부터 경로 매핑과 패키지 생성까지 데스크톱 UI에서 이어서 처리하도록 구성했다.
