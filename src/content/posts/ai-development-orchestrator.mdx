여러 대규모 프로젝트를 각자의 AI 에이전트가 맡더라도, 요구사항과 설계, 중요한 판단은 사람이 계속 책임질 수 있는 개발 파이프라인을 만들고 싶었다. AI Development Orchestrator는 에이전트의 구현 능력을 활용하면서 사람의 승인과 개입을 흐름 안에 두는 시스템이다.

오케스트레이터가 Claude Code 헤드리스 세션을 실행·중단·재개하고, 에이전트 간 질문과 답변을 승인 게이트를 통해 전달한다. Hook으로 활동 이벤트를 기록하고, Scribe 에이전트가 의사결정의 배경과 근거를 남긴다. 관리 CLI에서는 상태 확인, 직접 지시, 의사결정 검토와 과거 기록 검색을 할 수 있다.

MCP 도구와 별도 프로세스 신원을 사용해 에이전트 간 통신을 오케스트레이터 경유로 제한했다. 스크래치 환경뿐 아니라 실제 사용자 프로젝트에 연결해 질문·답변, 개입, 기록, 여러 프로젝트로 확장하는 흐름을 검증했다.
